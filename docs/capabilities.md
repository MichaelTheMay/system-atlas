# Capability matrix

What Atlas can and cannot see today. Every row is either backed by a test or marked as planned.
Unsupported areas appear in the product as coverage gaps, never as silence.

| Area                                                     | Status                               | Depth                   | Boundary                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------------- | ------------------------------------ | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Generic inventory (any repo)                             | available (A03)                      | inventory               | Obeys .gitignore/.atlasignore; skips binaries, secrets, vendor/build output; no symlink escape                                                                                                                                                                                                          |
| TypeScript / JavaScript                                  | available (A04)                      | deep                    | Packages, imports/exports (bundler-style resolution inside the root), exported declarations, explicit server routes, fetch/axios consumers, BullMQ queues, SQL strings (heuristic), react-router routes. Per-file facts are cached by content hash (M01)                                                |
| Python                                                   | available (A04)                      | syntax + explicit rules | Imports (ambiguous ones reported), functions/classes, explicit FastAPI routes, console-script entrypoints                                                                                                                                                                                               |
| Docker Compose / Dockerfile / SQL migrations / manifests | available (A04)                      | config                  | Declared services, images, tables and packages only                                                                                                                                                                                                                                                     |
| Go, Java/JVM                                             | planned (Phase 4)                    | —                       | Reported as unsupported language until then                                                                                                                                                                                                                                                             |
| Other languages                                          | not planned                          | inventory               | Source browsing only; semantic analysis unavailable (gap)                                                                                                                                                                                                                                               |
| Dynamic dispatch, reflection, generated code             | never complete                       | —                       | Reported as gaps; no complete call graph is promised                                                                                                                                                                                                                                                    |
| Live updates (watcher)                                   | available (M01)                      | local filesystem        | Watches directories with inventoried files plus new non-excluded ones; dependency/build folders are never watched. Edits coalesce (750 ms quiet, capped wait). Only TS/JS is incremental; other analyzers rerun in full                                                                                 |
| Process runs (`atlas run`)                               | available (E02)                      | runtime                 | Commands the user explicitly runs; argv only, no shell interpolation                                                                                                                                                                                                                                    |
| Browser evidence (Playwright helper)                     | available (E03)                      | runtime                 | Only instrumented contexts/pages; screenshots prove a captured state, not workflow success                                                                                                                                                                                                              |
| Output-to-code correlation                               | available (E04)                      | runtime                 | Explicit entity IDs and command mapping (supported); route signature (inferred); otherwise "unknown", never guessed                                                                                                                                                                                     |
| Coding agents (MCP, `atlas mcp`)                         | available (I01)                      | read + record           | Read the map, evidence and runs. Record runs, events and artifacts. Scoped to one project; no filesystem, SQL or command tools; reads paginated and trimmed                                                                                                                                             |
| Generic event SDK                                        | available (I01)                      | runtime                 | Node programs: `startRun` + `recorderFor` via `localDaemon()`. Other languages: HTTP ingestion protocol                                                                                                                                                                                                 |
| Third-party browser agents                               | partial (I01)                        | runtime                 | Only via SDK/MCP recording; directory watching is a degraded adapter                                                                                                                                                                                                                                    |
| OpenTelemetry traces                                     | available (I03), documented subset   | runtime                 | OTLP/JSON trace files via `atlas import`: spans become steps and tool calls, nested by parent. Protobuf, logs, metrics, links and bytes values are not imported; every incompatibility is a diagnostic and a capture gap (docs/evidence.md)                                                             |
| Imported run bundles                                     | available (I03)                      | runtime                 | `atlas-run.json` plus files; never linked to a snapshot; paths confined to the bundle; re-imports dedupe and append late events                                                                                                                                                                         |
| VS Code integration                                      | dropped (user decision 2026-10-26)   | —                       | Not planned                                                                                                                                                                                                                                                                                             |
| JSON Canvas / Mermaid export                             | available (I04)                      | export                  | `atlas export`: linked JSON Canvas 1.0 views, run canvases with hash-verified artifacts, simplified Mermaid; a sidecar maps nodes to Atlas ids; unsupported features are disclosed (docs/export.md). No Skena bridge                                                                                    |
| Model enrichment                                         | available (M02), no network provider | inferred                | Agents propose cited claims through MCP; built-in enrichment is off by default with mock providers only (cache, daily budget, cancellation, redacted bundles, explicit requests only). Claims are validated, stored as inferred, stale on change and rejectable. View proposals are not implemented yet |
